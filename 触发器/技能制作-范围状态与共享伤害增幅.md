# 技能制作：范围状态与共享伤害增幅

用途：制作友方可进入、离开或重复进入的技能领域，并将领域状态接入地图真实伤害系统。本页来自《一剑爆开天门》源码备份的启用 GUI、物编只读结果与作者确认；仅作原理参考，未经目标图游戏或多人验证。rawcode、对象名称、范围和时间仅属于本图。

## 源码中一条跨 GUI 和物编的链路

【中心系统 → Meimiao100 → FQA158 游龙剑阵】按玩家的技能拥有或吞噬状态、独立计数与冷却条件运行；在英雄周围随机选择坐标，尝试最多10次寻找可行走地位置，再创建属于该玩家的剑阵马甲，设置5秒限时生命。本次只读 GUI 中，10次都没有找到可走点时仍需核对最终坐标和游戏表现；新图可根据设计明确重试、跳过或安全回退，不假定必有可行点。0.1秒计数、缩减系数和零缩减时的具体规则须按目标图核对。

本图马甲 `e01M` 的已修改物编技能列表含 `A096`；`A096` 使用原生光环模板 `AIae`、作用范围280、关联 Buff `B001`，目标参数包含存活、地面、友方、自身等条件。`B001` 物编说明为剑阵增伤状态。【一些触发传输 → Dislpay_Sh → FQA158】检查参与计算玩家的绑定英雄是否拥有 `B001`，有时把当前伤害独立乘以 `1 + 0.15`，随后还有最终伤害分组。普通攻击及技能只在各自确实经过该公共计算时适用，不能据此推断地图中所有绕过计算器的伤害都已享受加成。

作者确认：**范围内的队友也应获得15%独立伤害增幅**；光环只是提供用于识别范围状态，伤害由触发计算，**不希望额外增加原生移动速度或攻击速度**。本次接口未读到 A096 所继承的原生光环数值，不能凭显示文本推断为0或已产生非零效果；实际制作、复用前应在目标编辑器核对和必要时设置真实数据，并在游戏中验证。

## 可复用设计，不照搬原始 ID

1. 定义领域的施放者、创建位置、半径、持续时间、受益阵营与有效单位类型；明确离开、回到范围、施法者死亡或多领域重叠时的规则。队友受益仅是本案例已确认设计，不代表其他技能默认相同。
2. GUI 创建领域并保留实例数据；可用无额外原生数值的光环状态辅助识别，或使用经验证的范围枚举。无论采用何种方式，都要处理光环刷新延迟、目标死亡及领域结束，不能仅依赖视觉特效表示增益。
3. 若状态只作为范围标识，伤害增幅应在目标图的中心计算中独立判断，不应同时把原生技能参数也配置成重复增益。先检查技能模板的继承字段、光环目标过滤和 Buff 对应关系。
4. 明确乘区和计算时机：本图例子是在技暴之后、最终伤害分组之前做独立乘法；具体技能是否享受、多人交错、目标防御和 BOSS 增伤按目标伤害系统确认。不要把“技能描述有15%”误当作完整计算或覆盖原有全伤害加成。
5. 检验多个友军、敌方、飞行单位、进入／离开／重叠领域、领域消失后状态残留及同时施放；区分 GUI 读回、保存编译、单人和多人实测。本次只做源码、物编只读核对。
